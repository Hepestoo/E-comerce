# ❓ ACLARACIÓN: .env vs .env.example vs datos.env

## Situación Actual en tu Proyecto

En `/back/` tienes:

```
datos.env          ← Archivo antiguo con credenciales REALES
.env.example       ← Archivo NUEVO que acabo de crear
```

## ¿Qué significa cada uno?

### 📄 `.env.example`
- **Propósito:** PLANTILLA de ejemplo
- **Contiene:** Nombres de variables SOLO
- **Credenciales:** NO (vacías o valores de ejemplo)
- **¿En Git?** SÍ (para documentación)
- **¿En Producción?** NO (es solo referencia)

Ejemplo:
```
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=tu_password_aqui
```

### 📄 `.env` (si lo crearás)
- **Propósito:** Configuración LOCAL
- **Contiene:** Valores REALES de tu máquina
- **Credenciales:** SÍ (tus datos locales)
- **¿En Git?** NO (está en .gitignore)
- **¿En Producción?** NO (cada servidor tiene el suyo)

Ejemplo:
```
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=Alanteck2004*
```

### 📄 `datos.env` (Archivo antiguo)
- **Propósito:** Archivo ANTIGUO del proyecto
- **Contiene:** Credenciales REALES
- **Credenciales:** SÍ (datos sensibles)
- **¿En Git?** NO (debe estar en .gitignore)
- **¿En Producción?** NO
- **¿QUÉ HACER?** 🗑️ ELIMINAR

## ✅ PASOS A SEGUIR (MUY IMPORTANTE)

### PASO 1: Renombrar datos.env a .env (FÁCIL)

En terminal, desde `/back`:

```bash
cd /home/teck/Escritorio/E-comerce/back

# Renombrar datos.env a .env
mv datos.env .env

# Verificar
ls -la | grep .env
```

**Salida esperada:**
```
.rw-r--r--  569 teck 11 Nov 17:04 .env
.rw-r--r--  213 teck 11 Nov 17:04 .env.example
```

### PASO 2: Verificar .gitignore tiene `.env`

```bash
cat .gitignore | grep ".env"
```

**Salida esperada:**
```
.env
.env.development.local
.env.test.local
.env.production.local
.env.local
datos.env
```

Si NO aparece, agregarlo manualmente:

```bash
echo ".env" >> .gitignore
echo "datos.env" >> .gitignore
```

### PASO 3: Verificar .env NO está en Git

```bash
# Ver si .env fue trackeado antes
git ls-files | grep ".env"

# Si aparece algo, ejecutar:
git rm --cached .env
git rm --cached datos.env
git commit -m "Remove .env and datos.env from Git tracking"
```

### PASO 4: Commit final

```bash
git add .gitignore
git commit -m "Configure environment files for production"
git push origin main
```
